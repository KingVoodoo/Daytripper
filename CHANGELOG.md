# Changelog

## 0.2.0

- Standalone Windows app with EVE sign-in and local map storage.
- Configurable home system and home display name.
- Mapping HUD with scanner, signature and wormhole connection workflows.
- Branded sign-in and callback screens, wormhole artwork, character cutouts and rotating tips.
- Arwes main interface, circuit background and optional interface sounds.

The Windows installer is attached to the GitHub release. Live EVE workflows require a linked character and an EVE client.
